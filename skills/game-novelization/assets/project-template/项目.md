# 游戏主线小说化项目

内部工作模板：只用于独立临时工作区，不随小说交付。

- 主角与影响剧情的自定义项：
- 本次交付范围与停点：
- 剧透边界：

## 表达约定

- 语言：简体中文
- 视角：第三人称限知；明确其他选择时替换
- 基调：保持原作气质
- 字数 / 分章要求：按用户要求；未指定时按事件自然组织
- 支线纳入原则：仅纳入支撑主线因果、关键人物关系或结局前置的部分
- 视频审阅：以完整细看和尽量获取细节为先，不为节省 token 或耗时降采样；先充分取材，再按剧情安排小说详略

## 原作风格档案

- 叙述语气与主要情绪（允许随剧情变化）：
- 当前叙述声音（距离、语域、句子节奏；同一游戏/本书已认可段落的依据）：
- 人物对白与称谓特点：
- 节奏、留白与信息揭示方式：
- 画面、空间、环境声与配乐带来的感受：
- 原作通过选择和代价呈现的主题：
- 对应来源 / 场景 / 视频时间段：
- 本书可执行的文风规则（少量具体约定）：
- 应保留的功能性修辞、停顿、复沓或旁白及作用（有则记，不凑项）：
- 需要细写的场景类型 / 可概述的重复过程：
