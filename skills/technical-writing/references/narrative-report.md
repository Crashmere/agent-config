# 叙述汇报模式编写指南

面向管理层汇报、专项综述、项目复盘、收益分析与阶段答辩。核心目标是在高信息密度下让读者看清**业务为什么需要它、关键难点在哪、架构与策略怎么破局、拿到什么可验证的量化收益**。

## 视角与语气

- **业务牵引 + 系统契约层叙事**：从业务动态与指标水位出发，先把业务诉求翻译成对工程架构的要求，再在系统、工作流和契约层面解释解法。**不堆砌文件路径、函数签名或常量定义**；仅在需要精确归因（如某条策略指标改善、某个具体接口失败率下降）时引用必要的接口名或策略标识。
- **书面紧凑、去口语化**：禁止“大家好，”“下面我来介绍一下……”等口语开场或串场词；内容应直接作为可供阅读与口头展开的结构化底稿。
- **客观坦诚、闭环完整**：既报成果也交代阶段边界、架构取舍代价，以及待推进项或负向指标决策（如因某核心指标负向按结论暂缓扩量、某方案因排期 Pending）。

## 两种常见结构形态（按需选用）

### 形态一：单专项综述 / 改造汇报
适用于围绕单个大型改造、治理专项展开纵深汇报：
1. **背景与现状**：业务现状与核心水位指标 → 现有链路/架构问题 → 结构化「痛点维度 | 现状 | 具体痛点（后果）」表。
2. **目标与阶段边界**：用双栏表对比「长期目标 vs 本次改造」，写明两者在操作角色、研发介入程度、耗时变化与维护成本上的边界。
3. **核心设计与验证**：说明配置载体/架构选型的取舍理由（把详细技术方案外链出去）；专节说明可靠性验证阶段（如 `PPE 单点自测 → 线上双跑只读 Diff → 分步切流`）、对上下游口径的影响与配套工具建设。
4. **架构对比**：用「改造前架构 vs 改造后架构」双栏图或机制对照，直观呈现范式迁移（如从强耦合变为阶段解耦）。
5. **改造收益**：用高亮块（`<callout>`）收口核心机制与前后量化对比。

### 形态二：多项目总结 / 阶段答辩汇报
适用于覆盖一段时间内的多个专项、能力建设与线上优化：
1. **业务背景与演进主线**：用简明定义说清业务目标、由此引出的**对研发侧的核心诉求**，再用「阶段 | 核心目的 | 关键动作 | 当前进度」表串联整体演进脉络。
2. **分主题子项目板块**：按能力建设、策略治理、底座复用、稳定性优化等主题组织；每个子项目按实际复杂度选用以下展开方式：
   - **单能力攻坚型**：背景（几句）+「难点 | 解决方式」两栏表（可配流程图与监控截图）+ 业务侧收益 / 技术侧收益 / 协作收益 + 未来计划；
   - **多子项并列型**：背景与目标（1～2 条）+「子项目 | 核心做法 | 收益」三栏总览表 + 工程演进关联；
   - **线上问题排查 / 调研型**：结构化四行表「问题现象 → 排查与定位（先写如何排除误判，再定位真因）→ 解决与收益 → 下一步」。

## 证据、图表与富文档模块

- **机制 + 硬数据对比**：所有“提效、降本、提准、稳定”结论都必须绑定具体机制与改造前后数字（如交付周期从 `0.5～1 天` 压至 `2～15 分钟`、同类需求 `80%` 免发版、失败率从 `20%～30%` 降至 `5%` 以下、周无效放出量 `-57.7%`、下游 `11` 个模型零改动），不写无依据的形容词。
- **画板与特殊模块优先**：灵活运用**画板（Whiteboard）、高亮块（Callout）、双栏对比与表格**。用画板替代复杂流程或架构的大段文字叙述；监控折线图、命中率/成本柱状图直接放在对应的排查过程或选型依据旁。
- **紧凑表格与分层外链**：具有多个属性或对比项的内容尽量收口成表格而非多层无序列表；详细技术方案、SQL 测算、归因分析与看板通过引用卡片挂在对应章节下，保持汇报主线清爽可读。

## 画板绘制规范（高层对比与分阶段视角）

绘制或审校叙述汇报画板时，先查看示例图确认风格：
- 红绿前后架构对比：[改造前后架构对比示例](examples/report-before-after.jpg)
- 多阶段行为与副作用泳道：[四阶段对比泳道示例](examples/report-stage-lanes.jpg)

绘制要求：
- **允许对比卡片，禁用花哨装饰**：可按需采用红绿“改造前 vs 改造后”架构对比或分阶段并列泳道卡片，但**禁用无意义装饰图标（如纯点缀 icon、小徽章、角标圆点）和过度拆碎的叠加文本框/编组**，保留清晰度与可维护性。
- **维持高层视角、突出对比与收益**：画板内容同样服从叙述汇报的高层抽象，用颜色、实虚线与空间对照直接让读者看出**问题在哪、机制怎么变、带来什么收益**（如红框/虚线标出耦合与回擦，绿框标出解耦与交付提效；实框与虚线框区分是否改变线上状态），不把代码细节或长段文字塞进画板。
- **一眼看懂、少字多图意**：节点内只写高凝练短语与关键数字，完整论证留在正文或表格中，确保打开画板即可从图形直观领会意图。
