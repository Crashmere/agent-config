# agent-config

个人维护的全局 Agent 指令与 Skills。

## 现有内容

- `AGENTS.md`：全局行为约束，包括 Python 环境安全、软件安装、指令管理和通用工作规范。
- `skills/openai-image-cost-report`：使用 OpenAI Image API 生成或编辑图片，并报告每次调用的费用。
- `skills/python-environment`：管理项目级 Python 虚拟环境、依赖安装和解释器问题。
- `skills/software-installation`：选择合适的软件来源和安装方式，执行安装、升级、卸载及结果验证。
